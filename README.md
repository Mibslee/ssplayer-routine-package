# ssplayer_package_creator

用本地已有的音乐、视频、原版波形图和封面制作 SSplayer 可导入的单文件资源包。可以交给 WorkBuddy、DeepSeek Harness、MiniMax Code 等智能体，也可以直接运行命令行工具。

- [安装与启动](references/agent-setup.md) 包含 WorkBuddy、dsh、MiniMax Code 和命令行的具体步骤。
- [制作和质检](references/quality-check.md) 包含命名、日期、封面、替换曲、AB 段、原谱和 App 验收。
- [SKILL.md](SKILL.md) 是智能体读取的入口。下载安装时保留完整目录和脚本。
- [文件格式](references/format.md) 说明清单与兼容要求。

## 快速开始

提供原始资料目录和输出目录。一次制作多套时，把各套的来源子目录、项目、套路号、版本和已确认的日期汇总成一张清单。可给整批设默认视频质量和署名，再为个别套路调整。一个套路产出一个文件，例如 `TONE_26_1.ssroutine`。

制作时就把已核实的动作时间线写进包。重复段先展开到每个动作和时间点，再核对换侧、拍数与原谱页。缺少可靠时间点的录音仍可保留原谱入口。详见[动作时间线制作](references/quality-check.md#把完整动作时间线写入包)。

在支持签注的 SSplayer 2.5.0 构建中，打开项目菜单的「从资源包导入」，可同时选择发布者给的 `.ssapproval` 和资源包。也可以先打开签注，再补选资源包，或从百度网盘选择文件。App 按包内项目代码建议归属。Pro 用户确认后，点「查看套路」核对分节和原谱，再用录音排课。

没有 Pro 也能先做离线质检。运行 `scripts/qa_preview.py --strict` 生成 9 张证据图、3×3 总览和可视报告 `report.html`。首图汇总封面、套路信息、包体积、视频分辨率、内嵌字幕轨和各项资料大小，可填写自己的署名。对位图基于包内媒体重新测量，报告可以逐首展开。有需要修正的实测问题时，报告会给出对应小节或文件类型。[质检命令与说明](references/agent-setup.md#生成九宫格质检图)

制包默认尝试高画质 HEVC，核对体积、抽样画质、时间戳、音轨与字幕后选用成品。也可选原画、iPad 或轻量档，并按需调整分辨率和码率。质检报告展示实际规格和重测后的对位结果。[视频质量选项](references/agent-setup.md#选择视频质量)

## 贡献资源包

构建完所选套路后运行 `ssroutine.py submit`。它逐套复测并生成一份可直接交付网盘的批次目录。目录里有 `套路资源包`、`质检图` 和一份随批次命名的 `.ssfingerprints.json`。每组质检图用对应包文件名的基名命名。发布者核对图片与指纹后签一份 `.ssapproval`，先导入这份签注就能接收对应批次的包。[批次提交和修订命令](references/format.md#batch-handoff)

先完成一套并约定提交渠道。累计 10 套不同套路，经开发者核验可用后可兑换 1 个月 Pro 激活码。同一套路的修订沿用原记录。制作人可以填写愿意公开的署名。GitHub Issues 用于报告制作工具问题。

本仓库的 Skill 和工具可下载到个人设备或 Agent 工作区，用于制作 SSplayer 套路资源包。请通过约定渠道提交有权分享的资料，原音乐、视频、波形图和封面的权利由各素材权利人决定。
