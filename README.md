# ssplayer_package_creator

用本地已有的音乐、视频、原版波形图和封面制作 SSplayer 可导入的单文件资源包。可以交给 WorkBuddy、DeepSeek Harness、MiniMax Code 等智能体，也可以直接运行命令行工具。

- [安装与启动](references/agent-setup.md) 包含 WorkBuddy、dsh、MiniMax Code 和命令行的具体步骤。
- [制作和质检](references/quality-check.md) 包含命名、日期、封面、替换曲、AB 段、原谱和 App 验收。
- [音画校时指南](references/video-clock.md) 说明怎么处理固定偏移、持续速度差和只能按画面验证的章节。
- [SKILL.md](SKILL.md) 是智能体读取的入口。下载安装时保留完整目录和脚本。
- [文件格式](references/format.md) 说明清单与兼容要求。

## 快速开始

提供原始资料目录。已选择项目工作目录时，成品默认放在其中的「交付」文件夹。也可为本批指定其他位置。一次制作多套时，把来源子目录、项目、套路号、版本和已确认日期汇总成清单，在同一步确认名称、封面、设置和实际交付路径。署名可在本机保存，可只改本批或更新默认。可为整批设视频质量，再为个别套路调整。一个套路产出一个文件，例如 `TONE_26_1.ssroutine`。

首次选公开署名时，输入你希望显示的名字。勾选「设为默认」后，下次确认时会预填。只想这次改名或不署名，可直接修改本批选项。

原始资料没有合适封面时，先请制作者提供。手头没有图片时，可以生成课程名和套路名组成的方形封面，先看预览，再确认入包。

制作时把已核实的动作时间线写进包。带绝对时刻的动作表可从原谱提取。像 GRIT 只印分段时长时，先区分动作表和技术讲解页，再用录音或视频核对起点与阶段边界。重复段按原谱核对顺序、换侧与拍数。详见[动作时间线制作](references/quality-check.md#把完整动作时间线写入包)。

在支持签注的 SSplayer 中，打开项目菜单的「从资源包导入」，从正式导入页选择本机或百度网盘。可以同时选发布者给的 `.ssapproval` 和资源包。也可以先打开签注，再补选资源包。App 按包内项目代码建议归属。Pro 用户确认后，点「查看套路」核对分节和原谱，再用录音排课。

包内小节功能可用于选曲筛选和搜索。不同课时、替选、连续 A+B 与 Express 专用录音来自已核对的原谱，课型模板导入从 SSplayer 2.5.1（2611.25.2）起可用。质检图列出需要复核的课型和需要从其他套路补齐的录音。

没有 Pro 也能先做离线质检。运行 `scripts/qa_preview.py --strict` 生成 9 张证据图、3×3 总览和可视报告 `report.html`。首图汇总封面、项目和套路名称、包体积、视频分辨率、字幕核验、各项资料大小及包内署名。视频定位、动作时间线和原版波形图按 SSplayer 手机备课页布局呈现。预览使用包内视频实帧、已核对的动作和原谱页，对位结果来自媒体复测。报告可以逐首展开定位需要修正的小节。[质检命令与说明](references/agent-setup.md#生成九宫格质检图)

九宫格显示每项结果。可修复的缺项或未核实的教学内容显示「暂缓交付」，修好后才能生成批次指纹。素材确实缺失时，在制作者确认的范围内显示「资料受限」，并说明还能使用哪些功能。

默认方案优先用 H.265（HEVC），核对体积、抽样画质、时间戳、音轨和字幕。未指定编码和尺寸时，压缩不能满足保真要求可保留兼容原视频。也可指定编码，或使用 iPad、轻量、原画档。质检首图展示实测编码、分辨率、体积和字幕轨。[视频质量选项](references/agent-setup.md#选择视频质量)

## 贡献资源包

核对素材、封面和设置后，运行 `ssroutine.py check-review`，通过后用 `finish` 构建和准备本地批次。批量用 `--keep-going` 交付通过项，后续可加入已构建的包接着完成。套路音乐按原文件字节入包，质检核对解码、时长并记录响度和真峰值。Mix 的音量和峰值调整使用 App 的「歌单响度一致化」。批次包含 `套路资源包`、`质检图` 和一份 `.ssfingerprints.json`。每套对应一张完整九宫格。发布者核对图片与指纹后，可用 Mac 签注工具生成 `.ssapproval`。[批次提交与续做](references/agent-setup.md#提交一批)

先完成一套并约定提交渠道。累计 10 套不同套路，经开发者核验可用后可兑换 1 个月 Pro 激活码。同一套路的修订沿用原记录。制作人可以填写愿意公开的署名。GitHub Issues 用于报告制作工具问题。

本仓库的 Skill 和工具可下载到个人设备或 Agent 工作区。制包和质检在本地运行。仅在确认分享权限和目的地后发送指定批次。原始素材、计划、日志和完整质检报告保留在本地。
