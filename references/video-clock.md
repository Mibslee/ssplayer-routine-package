# 视频章节和音乐时钟怎么核对

先确认小节、正曲或替换曲、A/B 段和录音版本。视频的整课时间、视频画面中的曲内计时、独立音乐的曲内时间可能有不同的零点。原谱上的动作仍按它所对应的录音核对。所有分析使用只读源文件，临时取样和复核数据放在工作目录。资源包内的音乐沿用原始文件字节。

## 从章节入手

1. 有内嵌章节时先查看整张表，再抽看章节切入、画面标题、计时器和下一个章节。核对热身、加曲、替换曲和拆分段的归属。相邻章节的起点可用于限定查找范围。短版和加曲可能在完整课的收操以后，核对片尾画面、课段标题和计时器，再判断这首录音是否拍摄。
2. 先运行分析，再对已确认的音频匹配候选做编码前复测。记录小节、视频章节范围、前中尾的有符号偏差、相关性和次峰差。正偏差表示匹配到的声音出现在预计时间之后。原始复核记录保存在工作目录。
3. `check-review --measure-video` 复测已批准的 `audioMatched` 候选。常规窗口难以分开人声和音乐时，工具用独立乐句、不同频段或视频内其他原始音轨复测。前、中、尾仍需支持同一时钟。可靠的移位证据会保留待核验状态。需要进一步复核时，换不同的节拍、过渡或乐句取样。

```sh
ffprobe -v error -show_chapters -of json "/path/to/source.mp4"
python3 scripts/ssroutine.py check-review reviewed.json --measure-video
```

对仍待核验的章节，可以在临时目录提取同一采样率的短音频。例子从音乐第 60 秒取 5 秒，候选视频章节从整课第 600 秒开始。视频样本在预计位置前后各预留 2.5 秒。

```sh
ffmpeg -v error -ss 60 -i "/path/to/music.mp3" -t 5 -map 0:a:0 -ac 1 -ar 4000 -f f32le "/scratch/music-60.f32"
ffmpeg -v error -ss 657.5 -i "/path/to/source.mp4" -t 10 -map 0:a:0 -ac 1 -ar 4000 -f f32le "/scratch/video-657.5.f32"
```

对两段临时 PCM 做归一化互相关。把匹配峰的样本偏移除以 4000，再减去 2.5 秒，就是相对候选视频时间的有符号偏差。前、中、尾各采样一次，再用不同乐句复测。检查主峰是否明显高于附近错拍或重复乐句的峰值。将结果保存在本地复核记录。

## 按偏差形状处理

| 实测情况 | 接下来做什么 |
| --- | --- |
| 三段偏差接近同一个数，多个乐句能对应 | 用中位偏差调整工作副本的候选视频起点，再换独立窗口复测。比如前、中、尾约为 +180、+190、+170 ms，可以将候选起点后移约 180 ms。校验调整后的整曲范围落在视频内。 |
| 单个乐句跳到 +1.6 秒，其他前、中、尾窗口都接近零 | 换开头附近的两个不同乐句和中尾的独立窗口复测。如果两组各自支持同一个时钟，检查冲突窗口是否来自相同副歌或节拍。一个有多个强峰的窗口不足以确认剪辑差异。 |
| 偏差随曲内时间稳定增加或减少，多个独立乐句确认是同一录音 | 分开拟合起点和速度比例，用未参与拟合的前、中、后窗口复核残差。保存每个锚点的音乐时间和整课视频时间、斜率、剩余偏差和素材身份。只记录两条时间轴如何换算。保留原始录音和视频。 |
| 偏差在切镜后跳变、出现不一致的斜率，或偏差缩小后相关性仍低 | 拆开核对各段和过渡，排查片段剪辑、不同混音或录音版本。优先找回已确认同版的录音或视频。证据不足时保留待核验，沿用原门槛，保留已有可核实的章节位置。 |

例如，若独立音乐第 30、90、150 秒分别可靠对到视频的 630.075、690.225、750.375 秒，拟合结果是 `videoSecond = 600 + 1.0025 × musicSecond`。0.25% 的差异累积到 5 分钟约为 0.75 秒，平移章节起点只能对齐其中一处。三点仍只是拟合示例，实际需用额外窗口复核，并排除整段编辑、错曲和重复乐句。

## 如实记录结果与交付范围

- **已核实曲内同步**需要工具用最终选用的素材复测通过。视频章节范围、音频证据和曲内时钟一起记录。
- **按视频章节跳转**可用内嵌章节、画面标题或明确的段落切入证明入口。可以把开始、结束和证据来源留在复核报告。该入口按视频自己的时钟观看，音乐和动作时间线的曲内同步保留待核验。
- **有证据的非单位速率映射**可以保留为核验记录。SSplayer 内部能用多锚点换算，现有 `.ssroutine` 章节字段只有起点、终点和证据。正式导入的 `audioMatched` 路径按等速映射处理。当前包中的多锚点复核记录仅作为本地证据，等待格式支持后才能用于导入校准。
- 正式带视频的共创包仍要求普通音乐小节通过曲内时钟门禁。只有视觉或近似证据时，先交代哪些小节可以按视频跳转、哪些不能跟随，并保留复核记录。已有视频按实际素材记录。`--source-limited` 的范围是经确认的原始资料缺项，已提供视频仍需核验曲内时钟。修正证据后再走正式投稿和签注。

见[共创包字段](format.md#music-and-analysis)及[制作和质检](quality-check.md)。


## 原视频的独立计时

同一发行版若可读到画面自带的小节名称和计时器，逐一比对开头、中段和尾段。保留 original 视频、音乐与时间基准，在相应小节的审阅中设 `chapter.evidence: "visuallyConfirmed"`，记录至少三个不同分段的 `visualClockSightings`。每条记录包含 `videoSecond`（整段视频的取帧时刻）与 `trackSecond`（画面计时器读数）。检查这些读数是否支持同一个小节起点，并保留相应证据帧备查。质检按视频自身时钟标注该曲。原视频确实没有拍摄的备选录音可标 `sourceVariantWithoutVideo`，仍需核对该录音、动作和原谱入口。
